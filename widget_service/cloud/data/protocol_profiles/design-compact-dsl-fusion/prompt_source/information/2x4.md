# 2x4 信息容量

<!-- prompt:capacity -->
### 2.6.9 2x4 信息容量

1. 单个对象的名称、状态和多个指标仍属于一个对象，不按字段数量拆分。
2. 一个主要对象可以携带最多两个具有独立决策价值的辅助信息组；辅助组不得重复主要对象已经表达的路径或同义事实。
3. 两个各自可独立理解的对象必须保持分区和操作归属；有明确主次时组织为一主一辅，用户要求等权比较时保持并列。
4. 三个或四个独立对象只保留各自最小充分信息：对象标识、核心事实，以及用户明确要求且能准确归属的操作。不得为填满容量增加弱字段。
5. 操作不增加数据对象数量。共享操作默认只保留一次；分别作用于不同目标的操作必须保持目标差异。
