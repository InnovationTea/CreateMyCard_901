# 小卡组件

<!-- prompt:selection -->
## 2x2 组件适配总表

| 组件 | 合法落点 / 容量差异 | 注意事项 |
|---|---|---|
| DataDisplay | 仅 S-center，唯一内容；新数值自适应，最小内容高126vp，文本126×122vp | 完整单焦点，无动作 |
| InfoBlock | 两个同级块仅用 S-dual-info，每块134×63vp | 不加 SingleLineTitle；variant 省略 |
| ProgressCircleSingle | 普通规格52×52vp，图标20vp | 不进入38vp双动作内容区 |
| ProgressCircle | 双/四比例模板专用槽 | 外框由槽注入，不输出宽高 |
| EventCard | 完整内容宽度，最大116vp | 长地点及多事件按完整高度验算 |
| PillButton | 登记的底部动作位，参考宽126vp、高36vp | 宽度由动作槽提供 |
| CircleButton | 仅 S-title-anchor 右下40×40vp | 单动作、准确SVG和独立支撑事实 |
| PillButton | S-content-dual-action标准双动作槽：有正文126×36vp | 两个实例各绑定一个必要动作；仅单行 |
| CardButton | S-content-dual-action的actions-only双动作槽：无正文126×57vp | 仅恰好两个动作、没有展示事实时使用 |

其它共享组件遵守各自容量合同。2x2不使用ProgressLine2、TextBlock、TopTextBottomValue、SummaryList；CardButton 仅可用于 S-content-dual-action 的 actions-only 变体。标题角色仅 SingleLineTitle，不使用标题数量 Group，Badge 不单独占槽。

## 2x2 图标预算

只允许标题、按钮、进度环心、S-dual-info 分区主视觉及 NumericRatioStack 内部图标，不直接生成图片或图文行。
默认最多2个20×20vp图标，标题/按钮/环心按最终实例计数；仅用户明确指定超过2个时允许超额，之后不再增可选图标。
NumericRatioStack 是例外：恰好三个12×12vp对象图标，独占本分区图标表达，不叠其它装饰。融球、轨道和文字不计图标，不用 emoji 绕过预算。
取舍依次保留用户明确指定、准确按钮图标、回答核心问题的内容视觉、可选标题；动作先于标题分配。无准确图标改文字动作，不能删操作或为标题牺牲准确按钮图标。
S-dual-info 每个信息单元最多一个主视觉（环心也算），辅助文本不配图；同类单元可复用准确src，
仍按两个实例计数。是否成立双信息块遵守组合合同，不为图标拆对象或补环。

## 2x2 组件细则

### InfoBlock 尺寸示例

普通信息槽省略 variant；两个同级 InfoBlock 必须放入无标题的 S-dual-info，不额外生成
SingleLineTitle。日期、城市、对象名或指标名属于块内辨识信息，应放在各自 primaryText / secondaryText，
“不要标题”不等于删除这些必要标签。用户明确要求独立可见标题或动作时，不使用双 InfoBlock 组合。
背板按小卡色。

```genui
["weather","InfoBlock",{"primaryText":{"path":"/data/weather/current/temperatureText"},"secondaryText":{"path":"/data/weather/current/condition"},"backgroundColor":"#CCFFFFFF"}]
```

```genui
["root","Layout",{"layout":"S-dual-info"},["first","second"]]
["first","InfoBlock",{"primaryText":"{{ '明天 ' + ${/data/weather/daily/1/condition} }}","secondaryText":"{{ '空气质量 ' + ${/data/weather/daily/1/airQuality} }}","backgroundColor":"#CCFFFFFF"}]
["second","InfoBlock",{"primaryText":"{{ '后天 ' + ${/data/weather/daily/2/condition} }}","secondaryText":"{{ '空气质量 ' + ${/data/weather/daily/2/airQuality} }}","backgroundColor":"#CCFFFFFF"}]
```

## 专属组件

### 1. `DataDisplay`

#### 选择条件

用于 2x2 无动作的完整单焦点：一个唯一核心读数或1–10字短文本结论，以及可选单位或紧密相关的次级标题信息。文本模式保留一条更新时间等紧密支撑。数值模式使用16fp主标题、可选紧密相关副标题及56fp数值/16fp单位；文本模式的上方标识可以是短标签，也可以是一个语义匹配的居中图标。
当整卡除紧密支撑外只有一个原本可由 `EmphasizedData` 或 `EmphasisText` 承载的核心信息时，优先改用
`S-center` + `DataDisplay`，不要让单个普通核心组件独占其它内容布局。这样由 `DataDisplay` 使用完整居中
内容区，而不是在卡片中留下无意义空白。
数值模式中同一核心的单行地点、状态、目标等紧密相关次级信息可放入secondaryInfo；
需要独立区域的备注、限定或明细改用普通核心组件加 `SecondaryBody`，不塞进标题区。另一对象或另一统计口径若与首项等权、各自能够独立理解，则不是从属补充：恰好两项时
各用一个 `InfoBlock` 并选择 `S-dual-info`，不能任取一项放大、再把另一项降为 `SecondaryBody`。

#### 组件属性

| Prop | 类型 | 绑定能力 | 要求 |
|---|---|---|---|
| `label` | string | 仅静态 | 与 `icon` 二选一；数值模式必填，文本模式可由图标替代 |
| `icon` | string | 仅静态 | 与 `label` 二选一；仅文本模式可用，逐字使用当前素材候选路径，运行时居中显示 |
| `value` | 显示值 | 静态 / Expression / PathBinding | 必填；唯一核心读数，或1–10字短文本结论 |
| `secondaryInfo` | 显示值 | 静态 / Expression / PathBinding | 新数值模式可选；同一核心的次级信息，单行；无必要信息则省略 |
| `unit` | string | 静态 / Expression / PathBinding | 新数值模式可选；独立单位，不重复主值已包含的单位 |
| `supportingText` | 显示值 | 静态 / Expression / PathBinding | 文本模式必填；旧数值模式兼容底部说明，不与新属性混用 |

#### 槽位与容量

仅进入 S-center 唯一内容区；新数值模式填满卡片内容区，文本模式最大126×122vp。数值单行显示；
文本结论最多两行。模型不提交 `fontSize`；Runtime 根据真实值或样例值确定模式，并由 Recipe 为数值核心
固定使用56fp、单位16fp；文本结论固定21fp，文本模式标签和支撑仍为12/14fp。
数值主副标题均16fp、各高21vp、间距2vp，标题区44vp；副标题缺失/null/静态全空白时主标题居中。
标题借鉴DoubleLineTitle的主标题＋紧密相关次信息，不承载第二个核心；不因标题字数或业务名称补造。
动态副标题保留绑定并条件隐藏整个副标题分组，数据源须将空白规范化为空串。
display不固定122vp：标题区44vp置顶，其下间距8vp；数值承载区以layoutWeight占剩余高度，
内部74vp数字单位行双轴居中，数字Text仍70vp、字号及字底补偿不变。
最小内容高126vp，低于所需容量不能缩字或裁切；数值与单位间距2vp，不猜测宿主像素。
旧数值supportingText仍走48fp底部说明兼容配方，不猜测说明是单位。旧 DSL 中遗留的 `fontSize`
只做兼容接收，不参与字号选择，也不因此触发修复。不得通过缩小字号容纳超过10字的正文。

#### 示例

```genui
["display","DataDisplay",{"label":"运动会倒计时","value":{"path":"/data/countdown/countdownDays"},"unit":"天"}]
```

文本结论使用21fp；上方label槽可以改用语义图标：

```genui
["display","DataDisplay",{"icon":"resources/base/media/air_fill.svg","value":{"path":"/data/weather/airQualityConclusion"},"supportingText":"10:30 更新"}]
```

#### 注意事项

值已包含完整单位时改用其他合适组件，不重复单位。文本模式不能同时输出label和icon；没有匹配素材时
使用静态短label，不伪造图标路径。`DataDisplay` 不是所有核心值的替代品：出现动作或需要独立区域展示的
从属补充字段时，改用对应布局中的普通核心组件、`SecondaryBody` 与动作组件；出现两个等权短事实时，
使用两个 `InfoBlock` + `S-dual-info`，不生成 `EmphasizedData` / `EmphasisText` + `SecondaryBody` 的伪主辅。

### 2. `CircleButton`

只显示图标、不显示文字，仅用于 `S-title-anchor` 的右下锚点操作。组件本体固定 `40×40vp`，
图标固定 `20×20vp`。

它不是文字按钮的失败回退。单动作、准确 SVG、正文事实可明确拆分为主信息与至少一项独立其它信息且
用户未要求显示动作文字时，可直接作为首选；其它信息进入左下支撑区，不要求固定三项，但不能为零。
左下可以使用 `SecondaryBody` 承载辅助事实，只要整卡其它位置已有核心信息组件；整卡不能只有
`SecondaryBody`、标题与按钮。标题、动作以及只在标题中展示的上下文不计作其它信息；没有独立左下
支撑事实时使用文字动作布局。

| Prop | 类型 | 绑定能力 | 要求 |
|---|---|---|---|
| `icon` | string | 仅静态 | 必填；逐字使用当前素材候选路径 |
| `accessibility` | object | 仅静态 | 必填；`label` 写完整动作名称，可选 `description` |
| `onClick` | EventHandler[] | 事件参数按事件 schema | 必填；恰好一个当前事件候选中的 handler |

- `icon` 和事件必须逐字使用当前候选。
- 不生成位置、圆角、宽高、padding、背景色或图标颜色；定位、尺寸和配色由 Recipe 与当前卡片色板负责。
- 满足上述单动作、准确 SVG、主信息与其它信息条件时优先使用，不以 `PillButton` 无法闭合为前提；不得与
  `PillButton` 表示同一动作。用户仅用“点击、点一下、打开、查看”等词描述动作，不等于要求卡面显示动作文字。

```genui
["play_action","CircleButton",{"icon":"resources/base/media/play_fill.svg","accessibility":{"label":"播放音乐"},"onClick":[{"call":"clickToDeeplink","args":{"intentName":"Music","bundleName":"","abilityName":"","uri":"hwmusic://play"}}]}]
```
